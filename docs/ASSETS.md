# منابع دارایی‌ها

- `office.png`: تصویر محیط اختصاصی تولیدشده برای این پروژه؛ بسته‌بندی محلی، بدون نیاز به API در بازی.
- `vazirmatn-regular.ttf` و `vazirmatn-bold.ttf`: وزیرمتن از مخزن رسمی rastikerdar/vazirmatn با مجوز SIL Open Font License 1.1. متن مجوز در FONT-LICENSE.txt.
- صحنه‌های حراست/بایگانی: تصاویر واقعی‌نمای بازسازی‌شدهٔ اختصاصی و بسته‌بندی‌شده در بازی.
- نمادهای رابط و آیکون اندروید: مسیرهای برداری سادهٔ نوشته‌شده در سورس پروژه.
- صدا: تولید در دستگاه با Web Audio؛ نت‌های آرام پیانو، لایهٔ محیطی و نویز فیلترشده. نمونهٔ صوتی بیرونی یا دیالوگ ضبط‌شده استفاده نشده است.

APK نام پروندهٔ اول را دارد؛ نام تجاری مجموعه و شناسهٔ نهایی ناشر هنوز تعیین نشده‌اند.

- `security.png`, `archive.png`, `suspects.png`, `evidence.png`: تصاویر واقعی‌نمای بازسازی‌شدهٔ اختصاصی. صفحهٔ شواهد یک شیت ۴×۴ است؛ هر مدرک کادر مجزای خودش را در رابط نشان می‌دهد. عکس‌ها اسناد واقعی پرونده نیستند و متن مدرک مرجع قطعی روایت است.
