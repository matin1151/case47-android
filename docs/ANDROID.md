# اندروید، نصب و انتشار

پوستهٔ اندروید بومی با Java و WebView است. فایل‌ها از یک مبدأ HTTPS محلی و مجازی به کمک shouldInterceptRequest خوانده می‌شوند؛ هیچ درخواست شبکه‌ای برای این مبدأ ارسال نمی‌شود. دسترسی file/content، mixed content و مسیرهای بیرون از assets بسته‌اند. JavaScript bridge وجود ندارد. برنامه هیچ uses-permission درخواست نمی‌کند.

- minimum Android: 8 / API 26
- compile و target SDK: 35
- شناسهٔ موقت آزمایش: ir.case47.lastcall.dev
- نسخهٔ فعلی: 0.5.1 / versionCode 6
- نام نمایشی: پرونده‌ها
- هیچ نامی برای مجموعه انتخاب نشده است.

## ساخت قابل تکرار

نیاز به Java 21، Python 3 و دسترسی دانلود ابزارهای رسمی دارید. `setup_android.py` Android platform 35 r02، build tools 35 و ECJ 3.38 را دریافت می‌کند. آدرس‌ها در اسکریپت ثبت‌اند؛ ابزارها وارد سورس محصول نمی‌شوند. مسیر پیش‌فرض /tmp/case47-tools با CASE47_ANDROID_TOOLS قابل تغییر است.

`build_android.py` منابع را با aapt2، Java را با ECJ و bytecode را با D8 کامپایل می‌کند؛ سپس فایل‌ها را داخل APK، zipalign و با apksigner امضا می‌کند. این روش برای پوستهٔ کوچک، نیاز به Gradle و دانلود مجموعهٔ وابستگی‌های آن ندارد. برای ادغام SDK پرداخت آینده، مهاجرت پوسته به پروژهٔ استاندارد Gradle توصیه می‌شود؛ موتور و داده تغییر نمی‌کنند.

## امضا

کلید تست در `.local/test-signing.jks` تولید می‌شود و در ZIP سورس تحویلی نیست. این کلید فقط برای آزمایش است و برای انتشار استفاده نشود. ساخت مجدد روی یک سیستم دیگر کلید تست جدید تولید می‌کند؛ آن APK نمی‌تواند روی APK با امضای قبلی به‌عنوان به‌روزرسانی نصب شود. پیش از حذف نسخهٔ قبلی، پیشرفت را از تنظیمات بازی صادر کنید.

شناسهٔ نهایی ناشر و کلید انتشار تصمیم مالک پروژه است. پیش از انتشار اول، شناسهٔ موقت باید با شناسهٔ نهایی جایگزین و کلید انتشار توسط مالک ساخته و در محل امن نگهداری شود. برای ادامهٔ به‌روزرسانی‌ها همان شناسه و امضا لازم است. کلید انتشار یا گذرواژه را در مخزن سورس قرار ندهید.

## رفتار دستگاه

- وضعیت/نوار ناوبری با WindowInsets برای دستگاه‌های جدید لحاظ می‌شود.
- دکمهٔ Back ابتدا پنجرهٔ باز را می‌بندد، سپس به انتخاب پرونده و بعد به خروج می‌رود.
- ذخیره پس از هر تغییر پیشرفت است؛ هنگام pause صدا متوقف می‌شود.
- در خطای بارگذاری یا توقف renderer پیام فارسی و دکمهٔ تلاش دوباره نمایش داده می‌شود.
- برنامه عمودی است. روی تبلت نیز صفحه از همان موتور استفاده می‌کند.

## چک قبل از انتشار کافه‌بازار

۱. اجرای واقعی روی سامسونگ هدف، یک دستگاه ضعیف و نسخه‌های اندروید پشتیبانی‌شده؛ بررسی WebView به‌روز.
۲. تست نصب/به‌روزرسانی/مرگ فرایند، حالت هواپیما، قطع صدا، دکمهٔ Back و بزرگ‌نمایی فونت دستگاه.
۳. نهایی کردن شناسهٔ ناشر، آیکون، تصاویر فروشگاه و متن معرفی؛ بدون انتخاب نام مجموعه تا تصمیم مالک.
۴. بررسی الزامات فعلی پنل کافه‌بازار برای target SDK، رده‌بندی محتوا و سیاست حریم خصوصی در زمان انتشار.
۵. آزمون SDK خرید واقعی روی محیط آزمایشی بازار، فقط پس از تأیید نسخهٔ اصلی.
۶. امضای release و ثبت نسخهٔ جدید؛ APK فعلی نسخهٔ انتشار نیست.

حریم خصوصی فعلی: بدون حساب، بدون تبلیغات یا تحلیلگر، بدون انتقال اطلاعات به سرور. پیشرفت فقط در WebView storage خود برنامه است. در نسخهٔ پرداخت این متن باید متناسب با جریان واقعی خرید به‌روز شود.
